Today we’re looking at the different ways R lets us pull out just the parts of a dataset we care about. We’ll start with base R, since everything else builds on it, then see how dplyr splits the job cleanly into selecting columns and filtering rows. Regular expressions help when we know what a value looks like but not exactly what it is. data.table gives us a fast, compact syntax for filtering, summarizing, and grouping in one step. We’ll finish with skimr for quick data summaries.

You can also subset using single or double square brackets. These provide you with more flexibility than $. They can also be more verbose. The primary difference between the two is that [ preserves the original data structure, while [[ discards it and simplifies.

[ and [[ allow you to specify specific ranges of columns and rows to extract. The arguments are passed as [row range, column range]. Leaving an argument blank returns all rows or columns.

Accessing rows and columns in data frames

# value in the first row and first column
data_gapminder[1,1]
## [1] "Afghanistan"
# values in the second row
data_gapminder[2,]
##       country continent year lifeExp     pop gdpPercap
## 2 Afghanistan      Asia 1957  30.332 9240934   820.853

Accessing multiple rows and columns at once

# values in the first 5 rows and first 3 columns
data_gapminder[1:5, 1:3]

## 1 Afghanistan      Asia 1952
## 2 Afghanistan      Asia 1957
## 3 Afghanistan      Asia 1962

Working with lists

# return the first element of a list
basic_list[1]
## $item_1
##  [1] "a" "b" "c" "d" "e" "f" "g" "h" "i" "j" "k" "l" "m" "n" "o" "p" "q"
## [18] "r" "s" "t" "u" "v" "w" "x" "y" "z"
# extract the first value from the first list item
basic_list[[1]][1]
## [1] "a"

You can specify the row and column to subset either by its name, wrapped in ““, or by its indexed number. However, if you want an item (value) from within a list, you need to simplify that object first with [[ and then apply a single [.

Comparison & Logical Operators

You can also filter your data to specific cases based on conditions. This is done by placing the condition within the subsetting operators.

select() allows you pick columns based on their names. It takes two arguments, a data set, and a set of parameters by which to select columns; that parameter could be a single name, a span of names separated with a :, or some other condition, like names starting with, ending with, or containing specific characters, or even by the data type held in the column. Regular Expressions: grep() and grepl() 🤔

  • Sometimes we don’t know the exact value we want to search or filter for, but we know what it looks like
  • Regular expressions (regex) let us describe that pattern (without knowing exactly what we’re looking for)
  • grep() returns the positions (or values) of matches; grepl() returns TRUE/FALSE for each element
fruits <- c("apple", "banana", "blueberry", "cherry")
grep("^b", fruits)                 # 2 3
## [1] 2 3
grep("^b", fruits, value = TRUE)   # "banana" "blueberry"
## [1] "banana"    "blueberry"
grepl("^b", fruits)                # FALSE TRUE TRUE FALSE
## [1] FALSE  TRUE  TRUE FALSE

We don’t always know the exact string we’re looking for, but we often know its shape: it starts with a certain letter, contains digits, ends in “.csv”. Regular expressions describe that shape. Use grep() when you want to know which elements match, and grepl() when you want a logical vector, which is handy inside filter() or subset().

Filtering and mutating with data.table

health_dt <- fread("../../data/health_data.csv") # load quickly with fread
health_dt[age >= 20, .(
  n = .N, # denotes
  mean_bmi_pre = mean(bmi_pre, na.rm = TRUE),
  mean_bmi_post = mean(bmi_post, na.rm = TRUE)
), by = group]
##           group     n mean_bmi_pre mean_bmi_post
##          <char> <int>        <num>         <num>
## 1:      Control    19     25.64737      25.74737
## 2: Intervention    19     25.87368      24.56842

The advantages of using data.table. data.table is fast…like really fast (built on C programming language). Expressive and logical i,j, by syntax. Does operations by reference meaning you don’t have copies of big datasets floating around in your environment.

data.table logic

  • DT[i, j, by]

  • i operator is row-wise, like a filter statement (used above)

  • j operator tells what to do and what to return

  • by operator tells what to group by

health_dt[age >= 20, # `i` operator
          # `j` operator for what to do
          .(n = .N,
            mean_bmi_pre = mean(bmi_pre, na.rm = TRUE),
            mean_bmi_post = mean(bmi_post, na.rm = TRUE)
            ), by = group] # by operator tells what columns to group our j, i operation over
##           group     n mean_bmi_pre mean_bmi_post
##          <char> <int>        <num>         <num>
## 1:      Control    19     25.64737      25.74737
## 2: Intervention    19     25.87368      24.56842

Column operators with data.table

  • .SD stands for subset data and is data.table shorthand for get all columns
health_dt[, lapply(.SD, mean, na.rm = TRUE),
          by = smoker,
          .SDcols = !is.character] # notice ! operator
##    smoker      id      age weight_pre weight_post  bmi_pre bmi_post
##    <char>   <num>    <num>      <num>       <num>    <num>    <num>
## 1:     No 19.1250 33.83333   77.99167    76.64583 26.01250 25.62083
## 2:    Yes 22.5625 38.50000   81.01875    79.33750 25.29375 24.29375
##    vo2max_pre vo2max_post  improved
##         <num>       <num>     <num>
## 1:   40.59583    42.51667 0.6666667
## 2:   40.15625    42.96875 0.8750000

data.table also plays well with functional programming. Truly can handle big datasets fread that would crash other base R reading funcitons. ! is.character tells data.table to operate mean on numeric columns only.

Subsetting column operations in data.table with `.SDcols

health_dt[, lapply(.SD, mean, na.rm = TRUE),
          by = smoker,
          .SDcols = c('weight_pre', 'weight_post')]
##    smoker weight_pre weight_post
##    <char>      <num>       <num>
## 1:     No   77.99167    76.64583
## 2:    Yes   81.01875    79.33750

We can also subset our data.table to specific columns by specifying a vector of col names we want to operate on.
